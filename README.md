# HS Scaffolding Website

Professional bilingual website for HS Scaffolding - Hassan Elecaptain

## Features

- **Bilingual Support**: Full English and Arabic translations with RTL support
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations
- **Portfolio Gallery**: Showcase of completed projects
- **Client Logos**: Display of trusted clients
- **Contact Form**: Easy-to-use contact form for inquiries
- **Interactive Elements**: Smooth scrolling, parallax effects, and hover animations

## Sections

- Hero/Home
- Services (Cuplock, Tube & Fitting, Clamp, Window Scaffolding)
- Portfolio
- Clients
- About
- Contact

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- SVG Graphics

## Deployment

This website is ready for deployment on:
- Vercel
- GitHub Pages
- Netlify
- Any static hosting service

## Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required - it's pure HTML/CSS/JS
